# Web Foundations — Learn HTML & CSS

A self-contained, beginner-friendly single-page learning app.

## Run locally
1. Open this folder in VS Code.
2. Open `index.html` in a browser, or use the Live Server extension.
3. No build step, package installation, framework, or internet connection is required.

## Included
- 10 progressive modules covering web fundamentals, HTML, CSS, layout, responsive design, accessibility, and publishing
- Knowledge-check quizzes with explanations
- Interactive HTML/CSS mini playgrounds in selected modules
- Browser-local progress tracking

Progress is stored in localStorage for the browser and device where you use the app. It does not automatically sync between devices.
